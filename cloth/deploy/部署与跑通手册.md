# 衣冠·AI复原工作台 v2 · 部署与跑通手册

适用：腾讯云主机（已装 Caddy，域名 cloth.migucomi.com）。全程约 30–60 分钟，其中填写密钥和逐个角色走流程占大头。

---

## 一、部署（一条命令）

登录服务器（SSH 或腾讯云控制台“登录”网页终端），进入 `shuzhiContent` 仓库目录：

```bash
git fetch origin claude/vibrant-cannon-51pg7i && git checkout FETCH_HEAD -- cloth
sudo bash cloth/deploy/install.sh --sample
```

- 过程中会问两次密码：先设 **admin（技术管理员）密码**，再设 **演示专家账号的共同初始密码**（wang 主审、li / zhang 评审、chen 运营）。
- `--sample` 会导入史氏像项目：主史料、观察记录、已签署的规格书 V1、此前 4 个模型生成的 6 张真实图，并已发起一轮评审。不加则是空库。
- 还没拿到任何模型密钥、只想先看流程：加 `--demo`。演示模式下未配置密钥的模型会输出带“模拟生成”字样的占位图，**正式使用前去掉 `--demo` 重新运行一次安装命令即可**（数据保留）。
- 域名不是 cloth.migucomi.com 时加 `--domain 你的域名`。

脚本最后会打印服务器公网地址。在 **DNSPod** 为 `migucomi.com` 添加记录：主机记录 `cloth`，类型 `A`，值为该地址（已有该记录则跳过）。生效后打开 `https://cloth.migucomi.com`。

说明：
- 之前部署过 v1 实验台的话，脚本会把 `/etc/caddy/cloth.caddy` 备份后改指向 v2；v1 服务（cloth-lab，端口 8790）和数据保留不动，不需要时执行 `sudo systemctl disable --now cloth-lab`。
- Caddy 校验失败时脚本自动恢复原配置，其他站点不受影响。
- 更新代码：重新执行上面两条命令即可，数据在 `/var/lib/cloth-v2` 保留。
- 日志：`journalctl -u cloth-v2 -f`。

## 二、需要哪些 API 密钥

用 **admin** 登录 → 系统设置 → 模型接入，在对应行填写密钥 → 保存 → 连通测试。

| 模型 | 用在哪 | 密钥从哪里来 | 一期是否必需 |
| --- | --- | --- | --- |
| **Seedream**（火山方舟） | ③ AI 生成；合拍模板；观众合拍（默认用它） | 火山引擎 → 火山方舟控制台 → API Key 管理；并在“开通管理”开通 Seedream 4.0 | **必需**（跑通全流程最少只要这一个） |
| **视觉读图 / AI 预评**（通义千问 VL） | ① AI 初读；④ AI 预评 | 阿里云百炼控制台 → API-KEY | 建议（不配时这两个按钮会提示未配置，可手工填写和打分） |
| Nano Banana（Google Gemini） | ③ AI 生成 | Google AI Studio → API key | 可选 |
| GPT Image（OpenAI） | ③ AI 生成 | OpenAI Platform → API keys | 可选 |
| Qwen-Image-Edit（本地 ComfyUI） | ③ AI 生成 | 不需要密钥，需要服务器能访问你电脑上的 ComfyUI | 可选 |

需要注意：
1. **Gemini 和 OpenAI 对香港、中国内地的调用有地区限制**。服务器在香港时，这两个模型很可能报地区不支持，连通测试会显示原因。一期建议以 Seedream 为主。
2. 接口地址和模型名已预填：Seedream `https://ark.cn-beijing.volces.com/api/v3` / `doubao-seedream-4-0-250828`；通义千问 VL `https://dashscope.aliyuncs.com/compatible-mode/v1` / `qwen-vl-max`。如果方舟控制台里的模型 ID 不同，以控制台为准修改“模型名”。
3. 本地 Qwen：服务器访问不到你家里电脑的 `127.0.0.1:8188`。要用的话，在电脑上建立到服务器的反向隧道（例如 `ssh -N -R 18188:127.0.0.1:8188 用户@服务器`），再把接口地址改为 `http://127.0.0.1:18188`。不用就保持未勾选。
4. “观众合拍”这一行的模型名填 `sd`（Seedream）。换成 `nb2` 即用 Gemini。
5. 密钥加密保存，页面只显示后 4 位。没有密钥的模型在生成页会显示“未配置”且不能勾选。

## 三、跑通全流程（按角色依次操作）

建议用两个浏览器（或一个普通窗口 + 一个无痕窗口）分别登录不同账号。下面以 `--sample` 导入的史氏像项目为例。

### 第 0 步 · 管理员准备（admin）
1. 系统设置 → 模型接入：填写 Seedream 密钥 → 保存 → 连通测试显示“已配置密钥”。（有通义千问 VL 密钥也一起填。）
2. 系统设置 → 成员与角色：可把 wang / li / zhang / chen 改成真实专家姓名，或邀请新成员。
- **检查点**：生成页 Seedream 可勾选。

### 第 1 步 · 史料汇集（wang 主审）
1. 复原项目 → 点“明 · 临淮侯夫人史氏命妇礼服”。
2. ① 史料汇集：已有主史料和 6 条观察记录，显示“已确认”。可以试：拖一张局部图上传；“粘贴链接”贴一个故宫或国博藏品页网址；有视觉密钥时点“AI 初读主史料”。
- **检查点**：史料库里每条有来源、许可和哈希；左侧“复原依据”显示主史料。

### 第 2 步 · 规格书（wang / li）
1. ② 形制规格书：V1 已签署锁定。
- **检查点**：字段不能再编辑；“AI 收到的提示词”能看到由字段拼出的提示词。

### 第 3 步 · AI 生成（wang）
1. ③ AI 生成：模型只勾 Seedream，每模型 2 张 → 点“① 生成初稿 · 生成 2 张”。
2. 等 1–2 分钟，任务进度变“完成 2/2”，画廊出现新图；点图可看模型、种子、规格书版本、参考图。
- **检查点**：新图不带“模拟”字样（演示模式下未配置的模型才会有）。失败时进度行会写原因，可“单独重试”。

### 第 4 步 · 专家评审（wang、li、zhang 分别登录）
1. wang：④ 专家评审 → “发起评审”，勾选候选图（可包含刚生成的 Seedream 图）、三位专家、开启盲评 → 发起。（导入数据里已有一轮 6 张旧图的评审，也可直接用那一轮。）
2. li、zhang、wang 各自：逐张点候选图 → 每项打分 → 在图上点一下加标注 → 勾选禁用元素 → 写意见；li 在某张图加一条修订建议，如 `F4` “两条带子并排垂于身前正中，不得做成背心” → 结论 → 提交评审。
- **检查点**：提交前看不到别人的分数；盲评时只显示“候选 A/B/C”；三人都提交后显示汇总、各人分数，分差 ≥ 2 的项标红“分歧”。

### 第 5 步 · 对比选择（三位专家 + wang 决定）
1. ⑤ 对比选择：看系统推荐前 3 名及理由；并排对比可选 2–4 张与原画像一起放大。
2. 每位专家在“我的首选”选一张、写理由（可写反对意见）。
3. wang 在“主审决定”选入选版本；与系统第一名不同时必须写理由 → 确定入选版本。
- **检查点**：推荐卡片显示专家首选票数；决定后顶部流程条 ⑤ 打勾。

### 第 6 步 · 修订 V2（wang、li）
1. ⑥ 修订：看到 li 提的 F4 建议 → wang 点“采纳”（或改写后“修改后采纳”）→ 系统生成规格书 V2 草稿。
2. ② 规格书切到 V2：li 把 F4 “校对通过” → wang 签署 V2。
3. 回到 ⑥ → “修订重生成”（以入选图为参考，只改修订项）→ ③ 画廊“修订重生成”里出现新图。
4. （可选）对新图再发起一轮评审，⑤ 重新决定。
- **检查点**：V1 不变；版本对比只显示 F4 的修改；新图的规格书版本为 V2。

### 第 7 步 · 定稿存证（wang）
1. ⑦ 定稿存证：选正面定稿图、授权等级选“可对外展示”、会签专家可选 li → 签署定稿并存证。
2. li 登录后在同页点“会签”。
3. wang 点“校验哈希”应显示“一致”；点“复原报告”可打印为 PDF。
- **检查点**：资产卡有资产 ID、SM3 哈希、签署与会签记录。

### 第 8 步 · 合拍模板（chen 运营 + wang 审核）
1. chen：顶部“合拍模板” → 定稿服饰选刚定稿的项目 → 生成 4 张模板（约 1–2 分钟）。
2. wang（或 li）：同页把模板与右侧定稿图比对 → 通过 / 不通过（写原因）。
3. chen：“换脸试跑”上传一张测试照片看效果 → “新建活动”填名称、起止日期、每日上限，勾选通过的模板 → 上线。
- **检查点**：活动卡片出现二维码和手机链接。

### 第 9 步 · 观众手机合拍（任意手机）
1. 微信扫活动二维码 → “我要合拍” → 选模板 → 勾选人脸信息授权 → 拍照或选一张正脸照。
2. 约 20–60 秒出图 → 长按保存。
- **检查点**：结果图右下角有“AI 生成 · 活动名”；不勾授权无法拍照；chen 在活动卡片看到今日次数、成功率；“抽检结果”只有合拍图，没有自拍原图。

全部检查点通过即为跑通。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 生成任务“失败 · 未配置密钥” | 系统设置 → 模型接入填写该模型密钥；或生成时不勾选它 |
| Seedream 报 401 / 403 | 密钥错误，或方舟控制台未开通 Seedream 模型 |
| Seedream 报模型不存在 | 把“模型名”改成方舟控制台显示的模型 ID |
| Gemini / OpenAI 报地区不支持 | 香港服务器调用受限，一期不勾选这两个模型 |
| AI 初读 / AI 预评提示未配置 | 填写通义千问 VL 密钥，或手工填写观察记录、手工打分 |
| 手机合拍“生成失败” | 合拍使用的模型（默认 Seedream）密钥是否有效；`journalctl -u cloth-v2 -n 50` 看原因 |
| 页面打不开 | `systemctl status cloth-v2`、`curl 127.0.0.1:8791/api/info`、DNS 是否指向服务器 |
| 忘记 admin 密码 | `sudo runuser -u cloth -- env CLOTH_DATA=/var/lib/cloth-v2 /opt/cloth-v2/venv/bin/python -m cloth.admin reset-password admin`（在 `/opt/cloth-v2` 目录执行）。`/etc/cloth-v2.env` 里的密码只在首次建库时使用 |
