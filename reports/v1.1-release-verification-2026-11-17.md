# v1.1.0 发布验证记录

日期 2026-11-17。PRD v1.1 已同步为 Markdown 和 9 页 Word，逐页渲染检查并修正标题边框及长接口换行。

## 本版变更

- 真实成果页 `/showcase` 随服务交付，公开花瓶 hero 和 WebXR 实际文件，支持旋转、切换、下载和渲染图入口；目录中的 7 个文件带大小与 SHA256。
- 精细展示预设 60000 面、2048 贴图、3 材质、30 MB；旧状态补齐该预设，保留已有预算和文件。
- 版本记录用途与档位，历史已批准版本可下载。真实模式重复加工从原始高模读取。
- 保留原路线图的真实执行边界，软件版本 1.1.0 不代表场景和重建引擎已接通。主界面持续显示流程演示或真实生产。
- 小孔先修补再判断是否需要体素重建，避免几乎封闭薄片产生双层表面拖慢 QuadriFlow。
- 修复 Docker 构建缺 VERSION，镜像包含样件；升级脚本保留旧容器与数据，独立端口预览后切换并支持失败回退。

## 部署状态

公网 `space.migucomi.com` 已存在，检测为 1.0.0 演示版。当前本机没有该服务器可用的管理 SSH 配置；已有 scw-tunnel 私钥仅为尚未启用的受限通道用途，不能当成管理员登录凭据。

浏览器控制工具因不能可靠判断当前 Windows 浏览器网址而停止了控制台操作。没有用其他浏览器自动化方式绕过这一限制。源代码、部署器和公网哈希检查器已准备，但仍须建立服务器命令执行通道，或由用户在现有服务器终端执行固定版本部署命令后再作公网验证。

本机升级器只读检查未发现部署容器；这不是云端部署验收。最终公网状态以 `python3 tools/verify_public_demo.py` 的实际结果为准。没有修改现有域名 DNS、Caddy、其他站点或云端数据。
