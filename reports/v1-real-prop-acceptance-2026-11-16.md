## 实现和实测覆盖

- 真实模式从空白工作区开始，仅开放 V1.0 道具；禁止用演示时钟或客户端字段生成成功状态。
- 真实上传、工作区隔离、不可变文件与版本、SHA-256、实际 Worker、单 GPU/三个 CPU、跨工作区排程、取消进程组、持久化与恢复保护已实现。
- ComfyUI、TRELLIS.2、DINOv3、BiRefNet、RMBG 依赖已接通；公开及受限权重均完成校验，凭据仅保存在本机。
- WSL 禁用本机不稳定的异步换载路径；去背景权重与输入类型一致；DINOv3 新 Transformers 布局保留原 conditioning 归一化语义。
- GPU 导出默认采用上游支持的原始表面处理，额外高成本 GPU remesh 需显式开启。后续实际执行 Blender 重拓扑。
- Blender 修复开放表面、限制重拓扑输入规模，并验证算子确实改变网格。清理、补洞、三角化在 UV 和烘焙之前完成，避免破坏已烘焙结果。重复优化始终读取原始高模。
- 高低模对比按各自中心和尺寸同步相机，解决原点变化导致的裁切。实际 GLB 支持六种材质模式、审核、入库、下载和压缩交付。
- 审核与导出绑定版本及文件哈希；导出前后复核许可证，排队后撤销许可会阻断交付。AIGC 标识写入文件并与来源核对。
- 四个角色密码已按用户要求统一更新，本机四账号登录实测通过。HTTPS Cookie 带 Secure，本机 HTTP 可用。
- Windows 当前用户启动任务保持 WSL 实际服务运行；本机平台 `http://localhost:8780`，ComfyUI `http://localhost:8188`。

CPU 自动测试使用明确标记的 TEST FIXTURE，不计为 AI 推理；上表单件 GPU 样本另有真实模型和任务证据。原演示模式 Windows 强制结束进程恢复用例此前失败，目标 WSL 环境对应恢复用例通过；真实模式采用逐写原子保存和 fsync。

UV 重叠为 512 网格像素采样；法线检查基于拓扑一致性和封闭体积方向，不能替代目检。固定版本 Khronos 校验器对压缩扩展有 6 条警告，另外执行 Draco 解码、索引/位置和 KTX2 检查及真实浏览器加载验证。
