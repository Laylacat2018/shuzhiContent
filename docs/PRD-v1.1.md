# AIGC 沉浸式空间内容生产管线平台产品需求文档

文档版本 1.1　软件发布 1.1.0　更新日期 2026 年 11 月 17 日

本版依据原《PRD 原型 SPEC》及真实道具闭环、蓝釉花瓶精修成果更新。目标是让项目团队能够生产可追溯的道具文件，同时向客户清楚展示产品流程和真实成果。此次软件小版本不等同于原路线图的“场景生产 V1.1”全部完成；场景、3DGS 与动画的真实执行仍按后续里程碑管理。

## 1 产品定位和本版决策

平台面向文旅、博物馆与沉浸式项目的产品策划、三维美术、审核和管理员。真实生产覆盖非文物本体道具的需求、概念图、图生三维、加工、质检、审核、入库和交付。文物本体须使用有依据的重建或人工制作流程，不允许以生成资产冒充真实文物。

本版新增精细展示母版档位、独立真实成果入口、原版与精修版对比、历史文件下载和版本用途记录。已有 WebXR、Quest 与大空间预算继续保留。不能仅用面数、贴图尺寸或自动质检通过，宣称视觉质量已经达到参考模型水平。

对外演示采用云端业务流程演示加公开样件展示。页面持续标明模拟流程；真实成果入口读取实际 GLB、贴图和来源记录。实时生成仅在接通真实生产节点、依赖就绪且许可范围允许时运行，云端演示不显示虚假的实际 GPU 推理结果。

## 2 用户角色和使用场景

| 角色 | 主要职责 | 关键限制 |
|---|---|---|
| 产品策划 | 建需求、上传参考图、查看进度与成果 | 不修改质检结论和模型许可 |
| 三维美术 | 选概念图、生成、按用途优化、人工精修交接 | 不把待审版本当已批准文件 |
| 审核人 | 复核几何与视觉质量、批准或退回版本 | 许可和 AIGC 阻断项不可人工绕过 |
| 管理员 | 模型登记、授权附件、预设、部署与审计 | 不以模型下载成功代替授权核对 |
| 演示访客 | 查看已发布花瓶样件、切换版本、旋转和下载 | 不访问私有工作区、原始客户素材或凭据 |

UC01 策划提交需求和真实参考图，美术确认概念图后进入生产。UC02 美术从原始高模分别制作精细展示版和终端交付版，审核按具体版本进行。UC03 客户不依赖 GPU 即可打开真实成果页，比较两档模型并查看实际渲染。UC04 管理员更新代码和镜像，保留已有数据与域名入口，并能够恢复上一版本。

## 4 生产流程和质量策略

需求登记与参考文件上传 → 概念图生成 → 去背景 → 人工选图 → TRELLIS2 → 保存原始高模 → 按用途加工 → 文件质检 → 多角度视觉复核 → 版本审批 → 入库 → 导出和解码验证。

原始高模必须保留。重复优化从原始高模开始，禁止在已减面的低模上累积减面后冒充母版。新加工结果创建新版本并清除当前版本批准标记；旧版文件和审批记录仍保留。版本记录包含 preset、purpose、raw_file_id、parent_task_id、file_sha256 和 created_at；renditions 记录每档最近版本，不表示自动批准。

| 用途 | 三角形上限 | 贴图上限 | 材质上限 | 文件预算 |
|---|---|---|---|---|
| 精细展示母版 hero | 60000 | 2048 | 3 | 30 MB |
| Quest3 道具 | 20000 | 1024 | 1 | 5 MB |
| WebXR 道具 | 10000 | 1024 | 1 | 3 MB 压缩交付 |
| XR 大空间 | 100000 | 2048 | 3 | 30 MB |
| 自定义 | 用户设定 | 用户设定 | 预设约束 | 按项目约束 |

预算是控制资源消耗的默认值，不是质量评分。精细母版保留未压缩文件；终端版的 Draco 和 KTX2 在交付阶段执行并重新检查文件预算。当前标准压缩路径仍使用已有配置，精细贴图的专门无损或高质量压缩选项列为后续优化项。

陶瓷专项精修参考 AI 模型的径向轮廓，重新制作中空壳体、内壁、底足和圆润瓶口；材质包含主色、法线、粗糙度、AO 和釉层。灯光高光不画进主色；效果图由实际三维文件渲染。展示尺寸不是实物测量，来源必须写明 AI 参考和程序化精修，不得标为实物扫描。

| P04 三维生成 | 加载实际 GLB，六种材质显示 | 用时为真实任务耗时，失败可追溯 |

| P06 场景生成 | 保留路线图原型 | 真实模式不开放未接入执行 |
| P07 实景重建 | 保留原型和采集记录需求 | 模拟结果不作真实重建精度报告 |
| P08 角色动画 | 保留路线图原型 | 不承诺已接通自动绑定或动作生成 |
| P09 场景组装 | 保留原型与确认流程 | 真实模式不开放未接入操作 |
| P10 质检审核 | 绑定具体版本与文件哈希 | 自动规则与视觉签收分开记录 |
| P11 资产库 | 历史版本标记质量档位，下载已批准文件 | 母版和交付版文件可追溯 |
| P12 导出发布 | 复核版本与许可并执行实际压缩 | 交付文件解码、哈希和体积通过 |
| P13 任务队列 | 真实模式显示实际进程与错误日志 | 无输出不自动标为完成 |

S01 展示花瓶精细版 50432 三角形和 WebXR 版 9446 三角形，支持旋转、缩放、重置、暂停旋转和实际文件下载。页面标记 AI 参考与程序化精修、尺寸为展示设定、未经头显验证。正面和俯视图来自实际三维渲染。此样件不作为百件每天或所有资产通用高质量能力的证明。

## 6 质量验收和业务规则

| 规则 | 检查内容 | 放行原则 |
|---|---|---|
| Q01 | 实际三角形数 | 不超过当前档位上限 |
| Q02 | 实际贴图分辨率 | 存在贴图且符合档位 |
| Q03 | 材质数 | 不超过当前档位上限 |
| Q04 | 非流形边 | 修复后为零或转人工处理 |
| Q05 | UV 重叠和缺失 | 512 网格采样，超限提醒人工复核 |
| Q06 | 法线方向和拓扑一致性 | 不一致需修复 |
| Q07 | 尺寸和底部中心原点 | 默认最大尺寸 0.1 至 3 米，偏移不超过 5 毫米 |
| Q08 | 实际使用模型与许可链 | 项目范围内合规，禁止人为绕过 |
| Q09 | 文件内 AIGC 标记 | 与来源记录一致 |

视觉验收补充五项：轮廓与参考一致性、薄壁和瓶口完整性、材质通道正确性、多角度光照下的表现、导出文件与渲染是否对应。必须能看到内壁或底部等容易被单视图掩盖的部位。视觉签收不能由自动规则全部通过推定。

审批绑定文件版本和 SHA256；新文件、新优化、人工交接或回退都必须保持记录一致。许可和 AIGC 阻断规则仍然有效。对外发布技术样件不意味着客户项目商用许可已清算；需要核对的范围在目录和交付清单保留记录。

## 7 数据和接口规格

沿用工作区、需求、任务、概念图、资产、版本、质检、审核、模型、许可和导出实体。生产写操作逐次原子保存并 fsync，真实文件独立索引。原有数据加载时补齐 hero 预设，不重置工作区、不重写旧文件、不提升旧版审批状态。

新增版本 purpose 取 hero 或 delivery；preset 标识实际档位；资产 renditions 将档位映射到最近生成的版本 ID。它们记录用途，不替代批准标记。旧数据无这些字段时仍能显示与下载。

| 接口或路由 | 行为 | 访问控制 |
|---|---|---|
| GET /showcase | 实际成果查看器 | 公开已发布样件 |
| GET /showcase/catalog | 版本、来源、两档规格与文件哈希 | 公开目录，无私有路径 |
| GET /showcase/assets/name | GLB、实际渲染和质检摘要 | 仅发布目录文件 |
| POST /api/v1/rpc optimize | 增加 hero 档位，原始高模为输入 | 已登录且有优化权限 |
| GET /api/v1/files/id | 下载工作区真实文件 | 登录与工作区归属校验 |
| POST /api/v1/qa/version/review | 按文件版本审批 | 审核权限 |
| POST /api/v1/exports | 锁定已批准的当前版本导出 | 复核文件与许可 |
| GET /healthz | 软件版本与健康状态 | 部署探针 |
| GET /api/v1/info | 软件版本与真实或演示模式 | 公开模式说明 |

历史批准版本可以下载；正式导出仍锁定当前已批准版本。自动多档联动审批、并行发布多个批准版本的导出接口尚待深化，本版不借字段存在宣称已经实现。

## 8 部署和运行要求

对外入口为 https://space.migucomi.com。云端演示采用 FastAPI、服务端 V8 业务状态和实际成果静态目录；不需要在云端复制 4090 模型环境。真实生产模式继续由本机 WSL 的 ComfyUI、TRELLIS 和 Blender 执行，数据目录与演示数据分离。

更新流程为测试、构建、版本冻结、备份现有配置与数据、在独立端口预览、检查登录与成果下载、切换服务、域名验收和保留旧版回退路径。不覆盖其他域名、不清空数据卷、不把凭据提交 Git。云端服务器命令通道尚未确认时，应报告部署待执行，不能根据 DNS 可解析或代码已推送宣称升级成功。

部署包需包含版本文件、前端本地依赖、服务器代码、公开样件、Dockerfile 和部署说明。敏感配置使用服务器本机私有环境文件，保留用户既有账号配置。四角色密码沿用当前用户设定，不写入 PRD、公开目录或仓库。

非功能要求包括 HTTPS、接口权限、工作区隔离、文件哈希、错误日志、发布回退和无外网依赖的模型查看器。公开页只展示经过明确选择的样件；客户照片和未批准文件不应因对外演示被公开。登录启动任务、数据备份和恢复演练要分别验收，不能用服务进程在线替代完整运维验收。

## 9 本版验收基线

真实 GPU 花瓶记录来自工作区 v1-gpu-acceptance：概念图与去背景 58.682 秒，TRELLIS 任务 341.990 秒，最后一次终端优化 11.092 秒，WebXR 版 9446 三角形，Q01 至 Q09 通过，压缩 GLB 421020 字节。该用时包含特定本机环境开销，不能直接折算承诺产能。

精修展示样件为 50432 三角形，2K 主色、粗糙度和法线，AO 1K；非流形边零、UV 重叠采样零，GLB 格式校验零错误零警告。制作来源为 AI 参考加程序化精修，非纯模型直接输出。具体哈希以 /showcase/catalog 和交付 quality.json 为准。

本版上线必须验证软件版本 1.1.0、登录、旧工作区恢复、hero 档位、真实成果加载与双版本切换、下载字节哈希、权限隔离、移动端基本可读性及原有站点健康。对外域名最终通过情况另写部署验收记录，本 PRD 不预先标记上线成功。

## 10 后续里程碑

第一阶段完成本版文档、质量档位、真实成果、仓库同步和域名演示升级。第二阶段将精修文件正式接入资产库和人工交接规范，补充多类真实道具及统一光照下的视觉签收。第三阶段开展百件每天压测、OOM 与取消实测、头显体验验收以及备份恢复演练。之后再按原路线图推进真实场景、3DGS、动画、云GPU和编排能力。

PostgreSQL Celery Redis 迁移、正式账号管理、自动保留期清理、商业许可完整核验、三视图一致性与逐面缺陷高亮仍为未完成项。里程碑按完成证据推进，不把演示按钮可操作等同于引擎已经接通。

本版未重述的原产品原则继续有效；涉及当前实现状态、精细展示、对外演示与发布的内容以本版为准。源文档作为历史基线保留，不覆盖原文件。
